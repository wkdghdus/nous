# Ralph Context Snapshot: M3 Review Queue

Timestamp: 2026-06-28T21:45:04Z

## Task Statement

Implement `.omx/plans/m3-review-queue-plan.md`.

## Desired Outcome

Add a dependency-free Ruby review workflow that lists pending inbox notes, claims, and relationships; shows evidence context; supports approve, reject, deprecate, merge, and edit actions; moves approved records into reviewed or canonical destinations; preserves audit metadata; and regenerates an Obsidian-friendly review queue report.

## Known Facts And Evidence

- `.omx/plans/m3-review-queue-plan.md` is the source implementation plan.
- `scripts/ingest_text.rb` and `scripts/test_ingest_text.rb` establish the current Ruby standard-library implementation and test style.
- `docs/architecture/vault-schema.md` documents inbox, reviewed note, canonical model, and generated report boundaries.
- `vault/02_notes/AGENT.md` lists reviewed note type directories.
- `vault/03_canonical_model/AGENT.md` lists canonical model directories but does not yet include relationships.
- `schemas/note-frontmatter.schema.yaml` currently has no review decision metadata.
- `Makefile` currently runs only ingestion tests through `make test`.

## Constraints

- Keep the workflow dependency-free and local-first.
- Preserve provenance and auditability; do not silently overwrite reviewed/canonical records.
- Notes require explicit reviewed type mapping on approval because inbox notes use generic `type: note`.
- Rejected, deprecated, and merged source items must remain on disk and fall out of the pending queue.
- Generated reports are convenience artifacts; item frontmatter remains the source of truth.
- `docs/shared/agent-tiers.md` is not present in this repo, so Ralph delegation tier guidance is unavailable locally.

## Unknowns And Open Questions

- Exact future UI shape is out of scope; the current repository has no application UI, so M3 is implemented as a CLI and vault-native report.
- The final long-term canonical graph export format remains future work; M3 only creates a canonical relationship destination and file transition workflow.
