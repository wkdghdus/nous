# Vault Signpost

This directory is an empty Obsidian-compatible vault skeleton. Keep raw artifacts and generated interpretations separate.

Direct children:

- `00_raw_artifacts/` - preserved source material and source records.
- `01_agent_inbox/` - generated notes, claims, and relationships awaiting review.
- `02_notes/` - reviewed human-readable notes.
- `03_canonical_model/` - accepted model records and curated summaries.
- `04_generated/` - generated reports and export files.
