This repository is Nous.

Project planning artifacts generally live under .omx/plans,
but their directory structure is not guaranteed to remain fixed.

Do not assume a particular milestone folder is authoritative based
only on its filename.

When determining current roadmap state:

1. Inspect planning artifacts recursively.
2. Identify the current authoritative PRD / execution map.
3. Identify milestone plans and test specifications.
4. Use verification reports and repository state as evidence of completion.
5. Prefer explicit execution-map/status statements over filename ordering.
6. Do not modify approved product scope without human authorization.

Engineering implementation should be delegated through the configured
Gajae Coordinator rather than directly improvising large code changes.
